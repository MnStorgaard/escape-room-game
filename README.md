# Detektiven i fængslet

A small browser escape room for kids aged 6-9 (Danish). One cell, 5 puzzles, ~10-15 minutes.

## Run
- `node serve.js` and open http://localhost:8080
- Or just double-click `index.html`

## Files
- `index.html` – page layout, start/end screens
- `style.css` – look and feel
- `game.js` – room objects, puzzles, hints, timer
- `sound.js` – generated sound effects and music (no audio files)
